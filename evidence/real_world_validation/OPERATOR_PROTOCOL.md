# Operator Protocol

Status: TEMPLATE_READY

## Rule 1

Every real-world validation action must be logged before promotion.

## Rule 2

Allowed actions should have receipts.

## Rule 3

Claim-related actions should have evidence references.

## Rule 4

Any incident must be recorded in INCIDENT_LOG.md.

## Rule 5

Real-world validation is scoped to the deployment context.

## Rule 6

Do not mark REAL_WORLD_VALIDATED_SCOPE_V0_1 until the validation gate passes.
